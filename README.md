# 欢迎使用 FCD（FUA CODE）

FCD 是一款由 FUA STUDIO 打造的 AI 编码代理。它能阅读代码、修改文件、运行命令、调试与构建，像一位随叫随到的工程搭档。

## 它能做什么

- **读写代码**：读取、创建、精准编辑项目里的任意文件，自动搜索与定位。
- **执行命令**：直接运行构建、测试、安装等 shell 命令，并解读输出。
- **真流式回复**：逐字实时输出，不等全部生成完才显示。
- **操控电脑**：截屏、移动鼠标、点击、输入文字、管理窗口、操作剪贴板，让 AI 替你操作图形界面。
- **MCP 扩展**：通过 Model Context Protocol 接入 Blender、Ghidra、IDA、Wireshark 等外部工具生态。
- **多模型自由切换**：内置 3 款免费模型，开箱即用；也可自带任意 OpenAI 兼容服务的 Key。

## 下载与形式

| 版本            | 平台         | 说明                         |
| --------------- | ------------ | ---------------------------- |
| FCD-Setup.exe   | Windows      | 一键安装，含 CLI 与桌面版    |
| fcd.exe         | Windows      | 命令行版，单文件免安装       |
| fcd-desktop.exe | Windows      | 原生桌面窗口版，无浏览器依赖 |
| fcd.elf         | Linux x86-64 | 纯命令行版，需系统 python3   |

## 三步开始

1. 运行 FCD-Setup.exe，选择安装目录（建议非系统盘）。
2. 启动后选择一个内置免费模型。
3. 直接输入需求，例如「帮我看下这个项目的结构」。

无需注册，无需配置，首次启动即自动就绪。

## 数据与隐私

所有配置、会话与用量数据都保存在安装目录的 data 文件夹内，便携可迁移，不写注册表以外的系统位置（仅卸载信息写于当前用户注册表）。随时可用卸载器彻底清除。
